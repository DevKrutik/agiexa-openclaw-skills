# Loox tools via Agiexa (5)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Loox and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/loox

| Tool | What it does |
| --- | --- |
| `LOOX_LIST_PRODUCT_REVIEWS` | List the merchant's Loox product reviews, filtered by Shopify product, star ratings (e.g |
| `LOOX_GET_PRODUCT_REVIEW` | Get one Loox product review by its Loox review ID |
| `LOOX_LIST_STORE_REVIEWS` | List the merchant's Loox store (shop-level) reviews, filtered by star ratings, status and date range |
| `LOOX_GET_RATING_SUMMARY` | Get the published average rating, review count and 1-5 star distribution for one Shopify product, or for all product reviews plus store reviews when n |
| `LOOX_PRODUCT_RATING_SUMMARY` | Rank products by average rating computed by OpenClaw from up to `max_reviews` recent product reviews (Loox has no ranking endpoint) |
