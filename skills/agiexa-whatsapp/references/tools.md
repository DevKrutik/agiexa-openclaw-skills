# WhatsApp tools via Agiexa (58)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects WhatsApp and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/whatsapp
