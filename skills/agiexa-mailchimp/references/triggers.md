# Mailchimp triggers via Agiexa (4)

Preview only - events that will be able to start an agent run after Agiexa launches (November 2026).

| Trigger | When it fires |
| --- | --- |
| `MAILCHIMP_CAMPAIGN_TRIGGER` | Triggered when a campaign is sent or experiences an event in Mailchimp |
| `MAILCHIMP_PROFILE_UPDATE_TRIGGER` | Triggered when a subscriber's profile is updated in Mailchimp |
| `MAILCHIMP_SUBSCRIBE_TRIGGER` | Triggered when a subscriber subscribes to Mailchimp |
| `MAILCHIMP_UNSUBSCRIBE_TRIGGER` | Triggered when a subscriber unsubscribes from Mailchimp |
