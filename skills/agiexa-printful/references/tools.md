# Printful tools via Agiexa (6)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Printful and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/printful

| Tool | What it does |
| --- | --- |
| `PRINTFUL_LIST_ORDERS` | List the merchant's Printful orders, optionally by status: draft, pending, failed (needs attention - address/printfile/charging problem), canceled, in |
| `PRINTFUL_GET_ORDER` | Get a Printful order's status, costs and shipments (carrier, tracking number and link) by Printful order ID or by Shopify order ID |
| `PRINTFUL_ESTIMATE_ORDER_COSTS` | Estimate what Printful would charge (products, shipping, tax) for items shipped to a destination |
| `PRINTFUL_GET_SHIPPING_RATES` | Get available Printful shipping methods, prices and delivery-day estimates for items shipped to a destination |
| `PRINTFUL_LIST_SYNC_PRODUCTS` | List products synced between the Shopify store and Printful, optionally searched by name or filtered by sync status (e.g |
| `PRINTFUL_GET_SYNC_PRODUCT` | Get a synced product and its variants (price, SKU, size/color, availability such as out_of_stock or discontinued) by Printful sync product ID or Shopi |
