# Yotpo Reviews tools via Agiexa (7)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Yotpo Reviews and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/yotpo-reviews

| Tool | What it does |
| --- | --- |
| `YOTPO_LIST_REVIEWS` | List the merchant's Yotpo reviews filtered by exact star rating, creation/update date and customer email, sorted by date or rating |
| `YOTPO_GET_REVIEW` | Get one Yotpo review (including unpublished) with its comment |
| `YOTPO_GET_PRODUCT_RATING` | Get a product's Yotpo average star rating and review count by Shopify product ID |
| `YOTPO_LIST_QUESTIONS` | List customer questions (with answers and product) - e.g |
| `YOTPO_SET_REVIEW_VISIBILITY` | Publish or unpublish one or more reviews on the storefront widgets |
| `YOTPO_COMMENT_ON_REVIEW` | Add the store's comment to a review - public (shown on the storefront) or private |
| `YOTPO_PRODUCT_RATING_SUMMARY` | Rank products by average rating computed by OpenClaw from up to `max_reviews` recent reviews (optionally since a date) |
