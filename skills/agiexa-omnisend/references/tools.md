# Omnisend tools via Agiexa (43)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Omnisend and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/omnisend

| Tool | What it does |
| --- | --- |
| `OMNISEND_GET_ORDER` | Tool to retrieve details of a specific order by ID |
| `OMNISEND_GET_BATCH_INFORMATION` | Tool to retrieve information about a specific batch by ID |
| `OMNISEND_GET_BATCH_ITEM` | Tool to retrieve a specific item within a batch by batchID and itemID |
| `OMNISEND_GET_BATCH_ITEMS` | Tool to retrieve processed items of a specific batch by ID |
| `OMNISEND_GET_BRAND` | Tool to retrieve information about the current authenticated brand |
| `OMNISEND_GET_CART` | Tool to retrieve a specific cart by ID from Omnisend v3 API |
| `OMNISEND_GET_CATEGORY` | Tool to retrieve details of a specific category by ID |
| `OMNISEND_GET_CONTACT` | Tool to retrieve details of a single contact by ID |
| `OMNISEND_ADD_CART_PRODUCT` | Tool to add a product to a cart in Omnisend (v3 API) |
| `OMNISEND_CREATE_BATCH` | Tool to create a new batch operation for multiple items |
| `OMNISEND_CREATE_CART` | Tool to create a new shopping cart in Omnisend |
| `OMNISEND_CREATE_CATEGORY` | Tool to create a new category in Omnisend |
| `OMNISEND_CREATE_ORDER` | Tool to create a new order in Omnisend v3 API |
| `OMNISEND_CREATE_OR_UPDATE_CONTACT` | Tool to create or update a contact in Omnisend |
| `OMNISEND_CREATE_PRODUCT` | Tool to create a new product in the Omnisend product catalog |
| `OMNISEND_CREATE_PRODUCT_CATEGORY` | Tool to create a new product category in the Omnisend catalog |
| `OMNISEND_DELETE_CART` | Tool to delete a cart from Omnisend by its ID (v3 API) |
| `OMNISEND_DELETE_CATEGORY` | Tool to remove a category from Omnisend by its ID |
| `OMNISEND_DELETE_ORDER` | Tool to delete an order from Omnisend by its ID |
| `OMNISEND_DELETE_PRODUCT` | Tool to remove a product from Omnisend by its ID |
| `OMNISEND_DELETE_PRODUCT_CATEGORY` | Tool to remove a product category from Omnisend by its ID |
| `OMNISEND_GET_BATCHES` | Tool to retrieve a list of batch operations |
| `OMNISEND_GET_PRODUCT` | Tool to retrieve details of a specific product by ID from Omnisend |
| `OMNISEND_GET_PRODUCT_CATEGORY` | Tool to retrieve a specific product category by ID |
| `OMNISEND_LIST_CAMPAIGNS` | Tool to retrieve a paginated list of campaigns with optional filtering by status and type |
| `OMNISEND_LIST_CARTS` | Tool to retrieve a paginated list of carts with optional filtering |
| `OMNISEND_LIST_CATEGORIES` | Tool to retrieve a paginated list of product categories |
| `OMNISEND_LIST_CONTACTS` | Tool to retrieve a paginated list of contacts with optional filtering |
| `OMNISEND_LIST_EVENTS` | Tool to retrieve all custom events created in Omnisend app |
| `OMNISEND_LIST_PRODUCT_CATEGORIES` | Tool to retrieve a paginated list of product categories from the Omnisend catalog |
| `OMNISEND_LIST_PRODUCTS` | Tool to retrieve a paginated list of products |
| `OMNISEND_REMOVE_CART_PRODUCT` | Tool to remove a product from a cart in Omnisend |
| `OMNISEND_REPLACE_CART` | Tool to replace an existing cart in Omnisend using the v3 API |
| `OMNISEND_REPLACE_CART_PRODUCT` | Tool to replace a product in a cart using Omnisend v3 API |
| `OMNISEND_REPLACE_CATEGORY` | Tool to replace a category's title by ID |
| `OMNISEND_REPLACE_ORDER` | Tool to completely replace an existing order in Omnisend |
| `OMNISEND_REPLACE_PRODUCT` | Tool to replace an existing product in the Omnisend catalog |
| `OMNISEND_SEND_EVENT` | Tool to send a customer event to Omnisend |
| `OMNISEND_UPDATE_CART` | Tool to partially update a cart in Omnisend (v3 API) |
| `OMNISEND_UPDATE_CART_PRODUCT` | Tool to update a product in a cart (v3 API) |
| `OMNISEND_UPDATE_CONTACT` | Tool to update fields of an existing contact by ID |
| `OMNISEND_UPDATE_ORDER_STATUS` | Tool to partially update an order status in Omnisend (v3 API) |
| `OMNISEND_UPDATE_PRODUCT_CATEGORY` | Tool to update an existing product category title in Omnisend |
