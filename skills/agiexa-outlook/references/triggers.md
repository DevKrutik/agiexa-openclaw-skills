# Outlook triggers via Agiexa (5)

Preview only - events that will be able to start an agent run after Agiexa launches (November 2026).

| Trigger | When it fires |
| --- | --- |
| `OUTLOOK_SENT_MESSAGE_TRIGGER` | Triggered when a new message is sent from the Outlook mailbox |
| `OUTLOOK_CONTACT_TRIGGER` | Triggered when a new contact is added in the Outlook contacts |
| `OUTLOOK_EVENT_CHANGE_TRIGGER` | Triggered when a new calendar event occurs (created, updated, or deleted) in the Outlook calendar |
| `OUTLOOK_EVENT_TRIGGER` | Triggered when a new calendar event is created in the Outlook calendar |
| `OUTLOOK_MESSAGE_TRIGGER` | Triggered when a new message is received in the Outlook mailbox |
