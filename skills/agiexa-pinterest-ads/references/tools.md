# Pinterest Ads tools via Agiexa (10)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Pinterest Ads and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/pinterest-ads

| Tool | What it does |
| --- | --- |
| `PINTEREST_ADS_GET_ANALYTICS` | Get synchronous Pinterest Ads performance metrics for an advertiser or selected campaigns, ad groups, or ads over a date range |
| `PINTEREST_ADS_GET_METRICS_READY_STATE` | Check whether Pinterest conversion and non-conversion metrics are finalized for a UTC report date before relying on analytics results |
| `PINTEREST_ADS_GET_TARGETING_OPTIONS` | Get Pinterest's valid targeting values for a targeting type, such as age buckets, gender, locale, location, interests, or keywords |
| `PINTEREST_ADS_LIST_AD_ACCOUNTS` | List advertiser accounts the connected Pinterest user owns or can access, including the IDs needed by all other Ads tools |
| `PINTEREST_ADS_LIST_AD_GROUPS` | List ad groups for an advertiser, filter by parent campaigns, or look up specific ad groups by ID |
| `PINTEREST_ADS_LIST_ADS` | List ads for an advertiser, filter by one hierarchy level, or look up specific ads by ID |
| `PINTEREST_ADS_LIST_CAMPAIGNS` | List campaigns for an advertiser, or look up specific campaigns by ID using campaign_ids |
| `PINTEREST_ADS_UPDATE_AD_GROUPS` | Rename, pause, or resume up to 30 existing ad groups |
| `PINTEREST_ADS_UPDATE_ADS` | Rename, pause, or resume up to 30 existing Pinterest ads |
| `PINTEREST_ADS_UPDATE_CAMPAIGNS` | Rename, pause, or resume up to 30 existing campaigns |
