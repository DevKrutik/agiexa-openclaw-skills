# Pinterest tools via Agiexa (26)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Pinterest and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/pinterest

| Tool | What it does |
| --- | --- |
| `PINTEREST_GET_INSPIRATION_TRENDS` | Get Pinterest editorial trend articles or featured trend topics for a supported region |
| `PINTEREST_GET_KEYWORD_TRENDS` | Find Pinterest's top growing, monthly, yearly, or seasonal search keywords for a supported market, optionally filtered to an audience or search terms |
| `PINTEREST_GET_MEDIA` | Get a registered Pinterest video's current upload or processing status by media ID |
| `PINTEREST_GET_PIN` | Get one public or secret Pinterest Pin by ID |
| `PINTEREST_GET_ACCOUNT_ANALYTICS` | Get aggregate Pinterest account analytics over a UTC date range, with optional metric, content, platform, source, and split filters |
| `PINTEREST_CREATE_BOARD` | Create a public or secret Pinterest board |
| `PINTEREST_CREATE_BOARD_SECTION` | Create a named section within a Pinterest board |
| `PINTEREST_CREATE_PIN` | Create an image, carousel, or registered-video Pin on a Pinterest board |
| `PINTEREST_DELETE_BOARD` | Permanently delete a Pinterest board by ID, including a secret board when authorized |
| `PINTEREST_DELETE_BOARD_SECTION` | Permanently delete a section from a Pinterest board |
| `PINTEREST_DELETE_PIN` | Permanently delete a Pinterest Pin by ID |
| `PINTEREST_GET_BOARD` | Get one Pinterest board by ID, including secret boards available to the connected account |
| `PINTEREST_GET_PIN_ANALYTICS` | Get daily, summary, and lifetime analytics for one Pinterest Pin over a date range |
| `PINTEREST_GET_PRODUCT_TRENDS` | Get currently growing shopping categories or detailed trend metrics for specified leaf product categories |
| `PINTEREST_GET_PROFILE` | Get the connected Pinterest account's profile and content counts |
| `PINTEREST_GET_TOP_PINS` | Return the connected account's top regular or video Pinterest Pins ranked by a route-appropriate analytics metric |
| `PINTEREST_GET_WEBSITE_VERIFICATION` | Get the connected account's website-claim verification methods and material |
| `PINTEREST_LIST_BOARDS` | List the connected account's public, protected, or secret Pinterest boards one page at a time |
| `PINTEREST_LIST_BOARD_SECTIONS` | List sections within a Pinterest board one page at a time |
| `PINTEREST_LIST_PINS` | List account Pins, Pins on a board, or Pins in a board section using one parameterized read tool |
| `PINTEREST_LIST_PROFILE_RESOURCES` | List followers, followed users, followed boards, followed interests, claimed websites, or linked businesses for the connected Pinterest profile |
| `PINTEREST_REGISTER_MEDIA` | Register a Pinterest video upload and return the media ID, upload URL, and all multipart parameters required to upload the video before creating a vid |
| `PINTEREST_SEARCH_OWN_CONTENT` | Search the connected account's own boards or Pins, including secret content when authorized |
| `PINTEREST_UPDATE_BOARD` | Update a board's name, description, or privacy |
| `PINTEREST_UPDATE_BOARD_SECTION` | Rename a section within a Pinterest board |
| `PINTEREST_UPDATE_PIN` | Update content on a Pin owned by the connected account or move it to another board or section |
