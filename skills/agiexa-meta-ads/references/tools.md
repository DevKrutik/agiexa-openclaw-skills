# Meta Ads tools via Agiexa (65)

Preview only - these become available to the agent after Agiexa launches (November 2026) and the merchant connects Meta Ads and turns the tools on. They cannot be called today.

Interactive explorer: https://agiexa.com/integrations/meta-ads

| Tool | What it does |
| --- | --- |
| `METAADS_CREATE_AD` | Create a new ad within an ad set using the Meta Marketing API |
| `METAADS_CREATE_AD_CREATIVE` | Create a new ad creative using the Meta Marketing API |
| `METAADS_CREATE_AD_SET` | Create a new ad set within a campaign using the Meta Marketing API |
| `METAADS_CREATE_AD_VIDEO` | Upload an ad video asset; Meta may keep processing it after returning its ID |
| `METAADS_CREATE_CAMPAIGN` | Create a new advertising campaign using the Meta Marketing API |
| `METAADS_CREATE_CUSTOM_AUDIENCE` | Create a new custom audience using the Meta Marketing API |
| `METAADS_CREATE_CUSTOM_CONVERSION` | Create a persistent custom-conversion definition in a Meta ad account and return its ID |
| `METAADS_LIST_CLIENT_AD_ACCOUNTS` | Tool to list all client ad accounts accessible to a business from Meta Ads |
| `METAADS_CREATE_LEAD_FORM` | Create a persistent lead-generation form owned by a Facebook Page and return its ID |
| `METAADS_DELETE_CAMPAIGN` | Delete an advertising campaign using the Meta Marketing API |
| `METAADS_GET_AD_ACCOUNTS` | Tool to retrieve all ad account IDs accessible to the authenticated user from Meta Ads |
| `METAADS_GET_AD_CREATIVE` | Get Ad Creative |
| `METAADS_GET_INSIGHTS` | Get insights data for a Meta Ads object (ad account, campaign, ad set, or ad) using the Meta Marketing API |
| `METAADS_GET_OBJECT` | Tool to retrieve data for any Meta Marketing API object by its ID |
| `METAADS_GET_PAGE_ACCOUNTS` | Retrieve pages managed by the authenticated user, including page access tokens when requested |
| `METAADS_GET_PIXEL_EVENT_STATS` | Read recent Pixel event-count and processing statistics, optionally restricted to server events and one event name, to verify aggregate ingestion |
| `METAADS_GET_USER` | Tool to retrieve information about the authenticated user from Meta (Facebook) Graph API |
| `METAADS_LIST_ACTIVITIES` | List activity history for a Meta ad account or ad set |
| `METAADS_LIST_AD_ACCOUNT_PIXELS` | List the Pixels and consolidated datasets associated with an ad account so a usable data-source ID can be selected for Conversions API events |
| `METAADS_LIST_AD_CREATIVES` | Tool to list all ad creatives under an ad account |
| `METAADS_LIST_AD_IMAGES` | List one page of image assets in a Meta ad account, optionally restricted to exact image hashes |
| `METAADS_LIST_AD_NETWORK_ANALYTICS` | Tool to retrieve ad network analytics for a Meta Business using the Meta Marketing API |
| `METAADS_LIST_AD_NETWORK_ANALYTICS_RESULTS` | Tool to retrieve ad network analytics results for Facebook Audience Network |
| `METAADS_LIST_ADS` | Tool to list all ads under an ad account using the Meta Marketing API |
| `METAADS_LIST_AGENCIES` | Tool to retrieve agencies associated with a Meta Business or Ad Account |
| `METAADS_LIST_ASSIGNED_PAGES` | Tool to retrieve Facebook Pages assigned to a business user via Meta Marketing API |
| `METAADS_LIST_ASSIGNED_USERS` | Tool to list users assigned to a Facebook Page or Ad Account within a specific business context |
| `METAADS_LIST_BUSINESS_AD_ACCOUNTS` | Tool to retrieve all ad accounts owned by a specific Business Manager |
| `METAADS_LIST_BUSINESSES` | Tool to discover every Business Manager the authenticated Meta principal can access, via `GET /me/businesses` |
| `METAADS_LIST_BUSINESS_INVOICES` | Tool to retrieve business invoices from Meta Marketing API |
| `METAADS_LIST_CAMPAIGNS` | List one page of campaigns belonging to a Meta ad account |
| `METAADS_LIST_CLIENT_APPS` | Tool to retrieve client apps associated with a Meta Business using the Marketing API |
| `METAADS_LIST_CLIENT_INSTAGRAM_ASSETS` | Tool to retrieve Instagram assets that are shared with a business as a client using the Meta Marketing API |
| `METAADS_LIST_CLIENT_OFFSITE_SIGNAL_CONTAINERS` | Tool to retrieve client offsite signal container business objects for a business from Meta Marketing API |
| `METAADS_LIST_CLIENT_PAGES` | Tool to retrieve client pages associated with a Meta business |
| `METAADS_LIST_CLIENTS` | Tool to retrieve client businesses associated with a Meta Business Manager |
| `METAADS_LIST_COLLABORATIVE_ADS_COLLABORATION_REQUESTS` | Tool to retrieve collaborative ads collaboration requests for a Meta Business using the Marketing API |
| `METAADS_LIST_COLLABORATIVE_ADS_SUGGESTED_PARTNERS` | Tool to retrieve collaborative ads suggested partners for a business from Meta Marketing API |
| `METAADS_LIST_COMMENTS` | Return one page from the comments edge of a Page-owned post, photo, video, comment, or reply |
| `METAADS_LIST_CUSTOM_AUDIENCES` | List one page of custom audiences in a Meta ad account, with field projection and optional business, primary-audience, or Pixel constraints |
| `METAADS_LIST_CUSTOM_CONVERSIONS` | List one page of custom-conversion definitions in a Meta ad account, with field projection and opaque cursor pagination |
| `METAADS_LIST_INITIATED_AUDIENCE_SHARING_REQUESTS` | Tool to retrieve initiated audience sharing requests for a business using the Meta Marketing API |
| `METAADS_LIST_LEADS` | List one page of leads belonging to a Meta Ad or Leadgen Form |
| `METAADS_LIST_MANAGED_PARTNER_ADS_FUNDING_SOURCE_DETAILS` | Tool to retrieve managed partner ads funding source details for a Meta Business |
| `METAADS_LIST_OWNED_APPS` | Tool to retrieve apps owned by a business from Meta Marketing API |
| `METAADS_LIST_OWNED_BUSINESSES` | Tool to retrieve businesses owned by a parent Business Manager from Meta Marketing API |
| `METAADS_LIST_OWNED_INSTAGRAM_ASSETS` | Tool to list Instagram accounts/assets owned by a Meta Business |
| `METAADS_LIST_OWNED_OFFSITE_SIGNAL_CONTAINER_BUSINESS_OBJECTS` | Tool to retrieve owned offsite signal container business objects for a business from Meta Marketing API |
| `METAADS_LIST_OWNED_PAGES` | Tool to retrieve Pages owned by a Business Manager from Meta Marketing API |
| `METAADS_LIST_PENDING_CLIENT_AD_ACCOUNTS` | Tool to retrieve pending client ad account access requests for a Business Manager from Meta Ads |
| `METAADS_LIST_PENDING_CLIENT_APPS` | Tool to retrieve pending client apps for a Meta Business |
| `METAADS_LIST_PENDING_CLIENT_PAGES` | Tool to retrieve pending client pages for a Business Manager using the Meta Marketing API |
| `METAADS_LIST_PENDING_OFFSITE_SIGNAL_CONTAINERS` | Tool to retrieve pending shared offsite signal container business objects from Meta Marketing API |
| `METAADS_LIST_PENDING_OWNED_AD_ACCOUNTS` | Tool to retrieve pending owned ad accounts for a Business Manager account from Meta Marketing API |
| `METAADS_LIST_PENDING_OWNED_PAGES` | Tool to retrieve Pages with pending ownership status for a Business Manager from Meta Marketing API |
| `METAADS_LIST_PENDING_USERS` | Tool to retrieve pending users from a Business Manager in Meta Marketing API |
| `METAADS_LIST_RECEIVED_AUDIENCE_SHARING_REQUESTS` | Tool to retrieve all received audience sharing requests for a business using the Meta Marketing API |
| `METAADS_LIST_SYSTEM_USERS` | Tool to retrieve system users for a Meta Business Manager account |
| `METAADS_LIST_TARGETING_SEARCH` | Tool to search for targeting options in Meta Ads Marketing API |
| `METAADS_LIST_VIDEO_TAGS` | Return one page of TaggableSubject entries from a Video's `/tags` edge |
| `METAADS_READ_ADSETS` | Retrieve ad sets from a Meta ad account using the Marketing API |
| `METAADS_SEND_CONVERSION_EVENTS` | Irreversibly submit 1-1,000 validated server conversion events to a Meta Pixel or dataset |
| `METAADS_UPDATE_AD_CREATIVE` | Update Ad Creative |
| `METAADS_UPDATE_CAMPAIGN` | Update an existing advertising campaign using the Meta Marketing API |
| `METAADS_UPLOAD_AD_IMAGE` | Upload an image for use in Meta ad creatives using the Marketing API |
